FunkyTreesEditor
================

A small, lightweight web-based editor for creating and editing SimplePlanes FunkyTrees. Uses the bundled Monaco editor for code-like editing and a simple UI served from static files.

Quick Start
-----------

- Open `index.html` in a modern browser, or serve the project folder with a static server:

  - `python -m http.server 8000` (then open `http://localhost:8000`)

- The editor assets are in `libs/monaco-editor/` and core logic in `editor/` and `tabs/`.

Development
-----------

- No build step required for basic use. If you add dependencies, use your preferred tooling.
